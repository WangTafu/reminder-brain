# 分类配置示例 / Category config example

> 这是默认的大类和分组。**你可以随便改**：增删大类、改名、改分组都行。搭建时 Claude 会问你要用哪套，确认后照着建表。
>
> These are the default categories and groups. **Change them freely**: add or remove categories, rename them, change the groups. During setup Claude will ask which set you want and build the tables to match.

## 默认（中文）

| 大类 | 分组 | 放什么 |
|---|---|---|
| 学习 | 阅读 · 技能 · 语言 · 课程 | 想读的书、想学的技能、在上的课 |
| 生活 | 证件财务 · 健康 · 爱好 · 休闲 · 旅行 · 购物 | 办证缴费、看病运动、兴趣、出去玩、要买的东西 |
| 工作 | 项目 · 沟通协作 · 职业发展 | 手头项目、要回的消息和要开的会、跳槽升职相关 |

## Default (English)

| Category | Groups | What goes here |
|---|---|---|
| Learning | Reading · Skills · Languages · Courses | Books to read, skills to pick up, courses in progress |
| Life | Admin & Money · Health · Hobbies · Fun · Travel · Shopping | Paperwork and bills, doctor and exercise, hobbies, going out, things to buy |
| Work | Projects · Communication · Career | Current projects, messages to answer and meetings, career moves |

## 其他人可能会这样改 / Other ways people set it up

- **学生 / Student**：课程 · 考试 · 社团 · 生活 / Classes · Exams · Clubs · Life
- **自由职业 / Freelancer**：客户 A · 客户 B · 自我营销 · 生活 / Client A · Client B · Marketing · Life
- **只要两类 / Just two**：工作 · 生活 / Work · Life

## 改了以后要同步的地方 / After changing, update

1. 项目说明里的「分类参考」/ the "Categories" section in your project instructions
2. 让 Claude 在 Notion 里加表或改单选选项 / ask Claude to add tables or edit select options in Notion
3. 完成档案「分类」的选项 / the "Category" options in the Archive table
