# 示例：一次整理

> 虚构的例子，看完就知道「整理执行页」会做什么。

## 整理前

速记里有 4 条：

| 事项 | 完成 | 正文步骤 | 进度 |
|---|---|---|---|
| 预约洗牙 | ✅ | | |
| 搭一个家庭 NAS | | 3 步，勾了 1 步 | 空 |
| 续签护照，6 月底到期 | | | |
| 买猫粮 | | | |

## 你说「整理执行页」，Claude 做四件事

**1. 归档（自动）**
「预约洗牙」打了勾 → 复制进「生活 · 足迹」和「完成档案」（分类「生活 · 健康」），速记里的原条目删掉。

**2. 算进度（自动）**
「搭一个家庭 NAS」3 步勾了 1 步 → 进度填 33，留在速记继续做。

**3. 问你分类**
剩下两条没开始，Claude 每条弹一张卡片，比如：

> **续签护照，6 月底到期**
> - A · 生活 · 证件财务 ★★★（推荐）：有截止日期
> - B · 生活 · 旅行 ★★☆：如果是为了某次旅行
> - C · 留在速记

你选：护照 → A，猫粮 → C。

**4. 收尾**
检查排序没被改，然后给你一个总结：归档了什么、算了什么进度、归类了什么、哪些留在速记。

## 整理后

- **速记**：剩「搭一个家庭 NAS」（33）和「买猫粮」
- **生活**：多了「续签护照」★★★
- **生活 · 足迹** 和 **完成档案**：各多了「预约洗牙」
