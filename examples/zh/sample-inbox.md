# 示例：一周的速记（中文）

> 以下全部是虚构的示例，用来展示速记里一般会记什么、正文里的步骤怎么写。

## 速记列表

| 完成 | 事项 | 进度 | 重要 |
|---|---|---|---|
| ☐ | 续签护照，6 月底到期 | | ★★★ |
| ☐ | 搭一个家庭 NAS 存照片 | | ★☆☆ |
| ☐ | 读完《原子习惯》第三章 | 30 | ★★☆ |
| ☐ | 给房东回消息，确认修热水器的时间 | | ★★☆ |
| ☐ | 买猫粮 | | ☆☆☆ |
| ☑ | 预约洗牙 | | ★★☆ |
| ☑ | 把季度报告的图表改成柱状图 | | ★★☆ |

## 有步骤的条目长什么样

**「搭一个家庭 NAS 存照片」**，点开后正文是：

- [x] 选好硬盘，下单
- [ ] 装系统，设好共享文件夹
- [ ] 手机相册设成自动备份

「进度」空着。整理时 Claude 数出 3 步勾了 1 步，把进度填成 33，这条算「正在推进」，留在速记。

**「读完《原子习惯》第三章」**，正文是空的（只有模板自带的一个空勾选框），但你在「进度」里自己填了 30。整理时 Claude 不覆盖你填的数，这条也算「正在推进」，留在速记。

## 没步骤的条目

「买猫粮」「预约洗牙」这类，正文什么都不写，做完直接勾「完成」。模板自带的那个空勾选框放着就行，Claude 不会把它当成步骤。
