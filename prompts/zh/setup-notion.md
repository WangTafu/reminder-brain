# 搭建提示词（中文）

> **怎么用**：先在 Claude 里连好 Notion 连接器，并按 `docs/zh/setup.md` 建好项目、粘贴项目说明。然后在这个项目里开一个新对话，把下面分割线之间的全部内容发给 Claude。
>
> Claude 会先问你几个问题（用什么大类、放在 Notion 哪个页面下），确认后再动手建表。

---

请帮我在 Notion 里搭建「reminder-brain」待办系统。规则以本项目的项目说明为准。请按下面的步骤做，每一步做完简短告诉我结果。

## 第 0 步：先问我，确认后再动手

用选择卡片问我：
1. **放在哪里**：在我的 Notion 里新建一个叫「执行」的页面，还是放在我指定的现有页面下面？
2. **大类和分组**：默认是下面这套，问我要不要改。我可以增删大类、改名字、改分组：
   - 学习：阅读 · 技能 · 语言 · 课程
   - 生活：证件财务 · 健康 · 爱好 · 休闲 · 旅行 · 购物
   - 工作：项目 · 沟通协作 · 职业发展
3. **要不要每周提醒**：要的话，问我星期几、几点（默认每周日 15:50）。

把我确认的结构列一遍给我看，我说「可以」以后再开始建。

## 第 1 步：建「速记」表

在「执行」页面里建一个数据库，名字叫「速记」。用整页数据库（不要 inline），这样它在执行页上只显示成一个链接，点进去才是表格。属性如下：

| 属性 | 类型 | 说明 |
|---|---|---|
| 事项 | 标题 | |
| 完成 | 勾选框 | |
| 进度 | 数字（普通数字，不要用百分比格式） | 说明写：「填 0–100，30 就是 30%；空着的话，整理时 Claude 按正文勾选框算」 |
| 重要 | 单选：☆☆☆ / ★☆☆ / ★★☆ / ★★★ | 说明写：「三星最重要」 |
| 计划日期 | 日期 | 可选 |
| 日期 | 创建时间 | |
| 最后编辑 | 最后编辑时间 | |

视图：
- 「待办」（表格）：显示 完成、事项、进度、重要、计划日期、日期；排序「完成」升序 +「日期」降序。
- 「🤖待归档」（表格）：筛选 完成 = 是。
- 「🤖待归类」（表格）：筛选 完成 = 否。

## 第 2 步：每个大类建两张表

对每个大类（比如「学习」），同样用整页数据库：

**待办表**，名字就叫大类名（例如「学习」），属性：
- 事项（标题）、完成（勾选框）、分组（单选，选项是这个大类的分组）、重要（同上的四档星）、进度（同速记）、备注（文本）、日期（创建时间）、最后编辑（最后编辑时间）

视图：
- 「按分组」（表格）：按「分组」分组，隐藏空分组；排序「完成」升序 +「日期」降序。
- 「🤖待归档」（表格）：筛选 完成 = 是。

**足迹表**，名字叫「大类名 · 足迹」（例如「学习 · 足迹」），属性：
- 事项（标题）、分组（单选，同上）、完成日期（日期）、重要（同上）、备注（文本）

视图：表格，排序「完成日期」降序。

## 第 3 步：建「完成档案」表

整页数据库。属性：事项（标题）、分类（单选，选项是所有「大类 · 分组」的组合，比如「生活 · 购物」）、完成日期（日期）、重要（同上）、备注（文本）。
视图：表格，排序「完成日期」降序。

## 第 4 步：把执行页排成色块

执行页上不要直接铺表格。每个区域放一个彩色色块（callout），色块里写：粗体标题、一句说明，然后放这个区域的表。表都是整页数据库，所以在页面上只是一行可以点进去的链接。这样一打开执行页，一眼就能看清整个结构。

布局从上到下：

| 色块 | 图标 · 颜色 | 位置 | 里面放的表 | 说明文字 |
|---|---|---|---|---|
| 速记 | ✅ 蓝 | 占满整行 | 速记 | 一周的暂存区：一行一条，只管记不用分类；最新的在最上面，做完打勾会沉到底部。有几步的事，点开在正文里写勾选框。说「整理执行页」时，做完的进足迹和完成档案，正在推进的留在这里，其余的用卡片问你归到哪个大类 |
| 学习 | 📚 紫 | 占满整行 | 学习、学习 · 足迹 | 这个大类的分组，加一句放什么 |
| 生活 | 🌿 黄 | 左栏 | 生活、生活 · 足迹 | 这个大类的分组 |
| 工作 | 💼 橙 | 右栏（和生活并排） | 工作、工作 · 足迹 | 这个大类的分组 |
| 完成档案 | 🏁 灰 | 占满整行 | 完成档案 | 所有做过的事的总账：每条带「大类 · 分组」标签，最新完成的在最上面 |

如果我的大类不是默认的三个：每个大类一个色块、一种颜色；第一个大类占满整行，其余的两个一组左右并排。

## 第 5 步：检查

- 把每张表的属性和视图读回来，确认和上面一致。
- 确认速记和各大类待办表的排序是「完成」升序 +「日期」降序。
- 读一遍执行页，确认每张表都在对应的色块里，并且显示成链接而不是展开的表格。
- 新建一条测试条目「测试：买牛奶」，确认能读写，然后删掉。

## 第 6 步：写工作笔记

在本项目里新建一个文档，叫「reminder-brain 工作笔记」，记录：
- 每张表的名字和内部地址（数据库 / 数据源 / 视图的 ID 或 URL），方便以后的对话直接找到。
- 我确认的大类和分组。
- 搭建日期。

## 第 7 步：每周提醒（如果我要）

用 Claude 的定时任务功能，按 `prompts/zh/weekly-reminder.md` 的模板建一个每周提醒，把里面的占位换成第 6 步记下的真实视图地址。如果这个环境里没有定时任务功能，告诉我，跳过这一步。

## 第 8 步：告诉我需要手动点的地方

有些设置 Notion 连接器做不了，最后请列给我，并写清楚在哪里点：
1. **进度显示成进度条**：点进速记表，点「进度」列名 → 编辑属性 → 显示为「进度条」，除以 100。大类待办表同样设置。
2. **默认模板**：点进速记表，右上角「新建」旁边的 ▾ → 新模板 → 正文里输入 `[]` 加空格放一个空勾选框 → 回到 ▾，在模板右边点「⋯」→ 设为默认 → 所有视图。
3. 如果某个视图的分组或排序没设上，告诉我在哪个视图、怎么点。
